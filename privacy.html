Privacy Policy

Last updated: May 27, 2026

This privacy policy applies to the following Chrome extensions developed by Sean V. (varseana@):

  • STAR Tracker — AHT tracking and queue management for Amazon Paragon
  • STAR Annotations — Annotation buttons and data capture for Amazon Paragon

Data Collection

These extensions do NOT collect, transmit, or share any personal data with external servers. All data remains on the user's device.

Data Storage

The following data is stored locally in the browser using chrome.storage.local:

  • STAR Tracker: Case timing statistics, queue configurations, AUX time records, daily/weekly metrics, user preferences (colors, toggles, layout settings)
  • STAR Annotations: User-created annotation buttons (title, text, category, color), folder organization, category color preferences

No data is sent to any external server, API, or third-party service.

Third-Party Services

These extensions do not communicate with any external servers, analytics platforms, or third-party services. All functionality operates entirely within the user's browser.

Permissions Used

  • storage — Save user preferences and operational data locally
  • tabs (Tracker only) — Detect active Paragon tabs for script injection
  • scripting (Tracker only) — Inject tracking scripts into Paragon pages
  • downloads (Tracker only) — Export statistics as CSV files to the user's device
  • alarms (Tracker only) — Schedule periodic tasks (daily reset, auto-export)
  • host_permissions — Access Amazon Paragon pages to inject UI elements

Data Sharing

We do not sell, transfer, or share user data with any third party. Data never leaves the user's browser.

Data Retention

Data persists in local browser storage until the user manually clears it (via reset/export functions) or uninstalls the extension.

Changes to This Policy

Any changes will be reflected in an updated version of this page with a revised "Last updated" date.
